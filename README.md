# CCAR Study Code

Live site: https://kman27.github.io/claude-architect-study/

Current version: **1.8.0** (2026-11-01). Release notes are in the app under `/changelog`.

A study app for the **Claude Certified Architect** exams, styled after the Claude Code terminal. It has two tracks: **Foundations (CCAR-F)** and **Professional (CCAR-P)**. Switch with `/track` or in `/config`; each track has its own plan, domains, quiz, exam facts and dates, while labs, projects and resources you finish count in both.

- `/start`: welcome and setup (track, eligibility, pace, optional API key, how the app works, key links). It opens on a first visit; after that the app opens to `/today`
- `/today`: readiness estimate, this week's items, what to do next
- `/plan`: 60 items for Foundations or 61 for Professional, each typed as read, course, lab, video, quiz, build or practice, packed into weeks at your chosen pace, each with a suggested slot and a **+cal** link to add it to Google Calendar
- `/domains`: the exam domains (5 for Foundations, 7 for Professional), weights, topics, common traps and your progress
- `/resources`: official courses, docs, Anthropic papers and webinars, blogs, GitHub repos, videos and practice exams
- `/labs`: 24 short guided labs, each built on an official guide (Claude cookbook, Platform and Claude Code docs, Claude Academy, MCP docs)
- `/projects`: eleven hands-on builds: seven for Foundations scenarios and four enterprise builds for Professional (RAG with evals, governance pack, architecture proposal, Claude Code rollout kit)
- `/quiz`: original scenario questions with explanations
- `/test`: a fresh practice test generated by Claude from the exam blueprint, with written answers graded by Claude as judge
- `/exam`: format, eligibility and registration steps for the selected track
- `/changelog`: version and release notes
- `/track [f|p]`: switch tracks
- `/config`: track, pace, study times, light or dark theme (Claude Code palettes), your Claude API key, export and import of progress

Type `/` in the prompt for command autocomplete.

## Your Claude API key

Ask Claude, generated quiz questions and the practice test call Claude. On GitHub Pages each visitor enters **their own** API key in `/config`, so nobody can spend your tokens through this site.

- The key is stored only in the visitor's browser (local storage if "remember" is on, otherwise for the current tab). It is never in the page source, this repo, or progress exports.
- Requests go directly from the browser to `api.anthropic.com`.
- Use a dedicated key with a monthly spend limit set in the Claude Console.
- All GitHub Pages sites under one `username.github.io` share a browser storage origin. Only host code you trust under the same account, or leave "remember" off.

## Hosting on GitHub Pages

1. Push this folder to a GitHub repository (the app is the single file `index.html`).
2. In the repository, open **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.
4. The site appears at `https://kman27.github.io/claude-architect-study/` within a minute or two.

## Notes

- Progress is stored in your browser (`localStorage`). Use **/config > Download progress file** and **Import progress file** to move it between devices or back it up.
- No build step and no dependencies. External requests: the JetBrains Mono font from Google Fonts, and the Claude API only when you use a Claude feature with your key.
- Exam facts reflect Anthropic's exam guides v1.0 (July 2026) and, for CCAR-P item counts, third-party summaries of the guide. The Professional practice scenarios are written for this app, not taken from the exam. Confirm details on the official certification page before booking.
